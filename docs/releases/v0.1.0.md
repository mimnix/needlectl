# needlectl v0.1.0

First public release: a command-line client for
[DroppedNeedle](https://www.droppedneedle.com/), built on its v3 REST API.

## Highlights

- **CSV playlist import** — Spotify-style exports are parsed tolerantly
  (UTF-8/UTF-16 BOM, CRLF, quoted commas, any column order) and matched against
  the DroppedNeedle library. Imports are idempotent and never duplicate tracks.
- **Library-aware linking** — rows already in the library are linked to their
  files, `playlist relink` fixes existing playlists, and entries whose track
  appears later are relinked on the next import.
- **Missing-track requests** — `playlist request` resolves the albums behind a
  playlist's unplayable entries through DroppedNeedle's MusicBrainz-backed
  search and requests one recording per track (the default), or the whole
  release group with `--albums`.
- **Cover repair** — `playlist repair-covers` re-links artwork through each
  album's MusicBrainz release group, for one playlist or with
  `--all-playlists`.
- **Library maintenance** — `album` and `track` `delete`/`rename`, with
  recycle-bin semantics, staged tag edits and `--keep-files`.
- **Drop import and held entries** — `import upload`, `import list`, and
  `held list`/`held match`.
- **Safe by default** — `--dry-run` previews every change, `--verbose` explains
  each decision, the password never appears on the command line, and the config
  is written `0600`.

## Requirements

- A DroppedNeedle v3 instance (3.0.0 or later).
- Go 1.27+ only when building from source; the release archives are
  self-contained.

## Upgrade notes

- First release, nothing to upgrade.
- Commands follow a resource-first grammar: `needlectl <resource> <operation>`
  (`playlist import`, `playlist relink`, `playlist repair-covers`,
  `playlist request`, `import upload`, `import list`, `held list`, `held match`,
  `album delete`/`rename`, `track delete`/`rename`). `login` is the only
  top-level verb.
